## Docs
### How do I download any mods?
1. Click [here](<https://mohammedkhalidmc.github.io/Ankle-Sprainers/>)!
2. In the top navigation bar press downloads, or in the homescreen press download.
3. choose the latest version and press download, or if you want to spice things up choose an old version and see the history of the mod.
4. Install the mod like you would any other!

### How do I send anything using the discord webhook?
1. Click [here](<https://mohammedkhalidmc.github.io/Ankle-Sprainers/>)!
2. In the top navigation bar press webhook.
3. write your text and press enter or `Send`, or if you want you could write LaTeX code but that will not be explained here.
